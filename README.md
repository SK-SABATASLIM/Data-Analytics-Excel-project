# Investment Dashboard (Excel)

## Overview
This project is an interactive Investment Dashboard created in Microsoft Excel. It provides insights into investment performance through charts, pivot tables, and slicers, helping users analyze and monitor investment data efficiently.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

## Key Features
- Investment performance overview
- Interactive filters using slicers
- Dynamic charts and visualizations
- Portfolio analysis
- Easy-to-understand dashboard
